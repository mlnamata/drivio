# Poznámka k této kopii

Zkopírováno z https://github.com/Leonxlnx/taste-skill (commit 12af471, licence MIT, viz LICENSE).

Přiložen je jen `SKILL.md` a složka `references/` (pravidla a seznam typických „AI“ prvků).
Složky `scripts/`, `library/`, `assets/` a `evals/` záměrně chybí: skripty ovládají prohlížeč
a stahují obrázky a pro tento projekt nebyly prověřené. Kde na ně SKILL.md odkazuje, použijte
místo nich kontrolu `npm run design:check` a snímky obrazovky přes Playwright.
